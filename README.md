# Nenn

Moderní webová aplikace postavená na Vite, React a Three.js s deployem na GitHub Pages.

## Začínáme

### Instalace

```bash
git clone https://github.com/akcizur/nenn.git
cd nenn
npm install
```

### Lokální vývoj

```bash
npm run dev
```

Aplikace se otevře na `http://localhost:5173`.

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Deploy

Po pushi do `main` se spustí GitHub Actions workflow a deployne build na GitHub Pages.

URL:
https://akcizur.github.io/nenn/

## GitHub Pages nastavení

V repozitáři jdi na:
- Settings → Pages
- Source: GitHub Actions

## Stack

- Vite
- React
- Three.js
- GitHub Pages
- GitHub Actions
